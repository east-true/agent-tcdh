# AgentTCDH v0.1.1

This patch release prepares npm republication after account migration and updates repository metadata and documentation to `jiind/agent-tcdh`. MCP metadata, the A2A Agent Card, and OpenAPI advertise version `0.1.1`. Runtime behavior and the discovery/direct-execution architecture are unchanged.

The previous npm package was withdrawn. npm does not allow reuse of a published package/version pair, so registry republication uses `0.1.1`. Entire-package removal also imposes a 24-hour publication delay. GitHub releases remain independently installable. See the [npm unpublish policy](https://docs.npmjs.com/policies/unpublish/).

## Install from GitHub

Requires Node.js 24 or newer. Install the built release tarball:

```sh
npm install --global https://github.com/jiind/agent-tcdh/releases/download/v0.1.1/agent-tcdh-0.1.1.tgz
agent-tcdh --help
agent-tcdh serve
```

The default hub URL is `http://127.0.0.1:3000`, and the default database is `~/.agent-tcdh/registry.sqlite`. Configure authentication through shell environment variables as described in the [reference](https://github.com/jiind/agent-tcdh/blob/v0.1.1/docs/reference.md).

## npm publication

GitHub publication does not imply npm publication. After the registry accepts version `0.1.1`, use:

```sh
npx --yes agent-tcdh@0.1.1 --help
npx --yes agent-tcdh@0.1.1 serve
```

## Verification and compatibility

The release workflow runs native regression and isolated package checks on Linux x64, macOS ARM64/x64, and Windows x64, plus Linux container checks. It then installs and exercises the exact GitHub tarball before publication. External provider calls and real model runs remain opt-in.

`SHA256SUMS` covers the tarball and `release.json`; the manifest binds the artifact to its version, tag, source commit, and SHA-256. Download all three assets and check them with `sha256sum --check SHA256SUMS` on Linux, `shasum -a 256 --check SHA256SUMS` on macOS, or `Get-FileHash -Algorithm SHA256` on PowerShell.

SQLite schema version 2 and portable snapshot format version 1 are unchanged. Existing registries and snapshots can be used with this patch release.
